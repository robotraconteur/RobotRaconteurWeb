# RobotRaconteur.Sharp Examples

This directory contains examples for RobotRaconteur.Sharp.

* [Reynard the Robot](reynard_the_robot): Examples using the Reynard the Robot cartoon learning robot, including
   examples of how to use Robot Raconteur features.
* [ASP.NET Core Server](aspnet_server): A minimal ASP.NET Core server hosting a Robot Raconteur service over
   WebSockets.
